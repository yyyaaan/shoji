# Agent handoffs

Follow [AGENTS.md](../../AGENTS.md#handoffs-between-agents).

- One active handoff per `<yyyy-mm-dd>-<from>-to-<to>-<topic>.md` file, with short role names.
- The receiving agent claims it using `Taken by: <role>, <date>`.
- Keep only outstanding actions; remove addressed items and delete the file when empty.
- Keep durable decisions/specifications in their owning documentation, linked from the handoff.
